# QA Gate

## Задача

        Проверь код Разработчика на соответствие архитектурному документу Архитектора.

        ЧТО ПРОВЕРЯТЬ:
        1. **Соответствие архитектуре**: все ли компоненты реализованы? Нет ли лишнего?
        2. **Безопасность**: SQL-инъекции, XSS, утечки секретов, небезопасные зависимости
        3. **Обработка ошибок**: все ли исключения обработаны? Нет ли голых try/except?
        4. **Валидация**: проверяются ли входные данные на всех endpoint-ах?
        5. **Тесты**: есть ли они? Покрывают ли основные сценарии?
        6. **Style guide**: PEP 8, нейминг, типизация

        ФОРМАТ ОТВЕТА:
        Для каждой найденной проблемы:
        - Приоритет: 🔴 (критично — блокирует запуск) / 🟡 (важно — нужно исправить) / 🟢 (минор — можно так)
        - Файл и строка (если применимо)
        - Описание проблемы
        - Предложение по исправлению

        В конце: ИТОГОВЫЙ ВЕРДИКТ — ✅ Go (нет критических проблем) или ❌ No-Go (требуются правки).
        Если No-Go — перечисли КОНКРЕТНЫЕ файлы и строки, которые нужно исправить.
        

## Результат

## Отчёт о проверке кода URL Shortener

### 🔴 Критические проблемы (блокируют запуск)

1. **Cache hit приводит к запросу в БД**  
   - **Файл:** `src/services/url_shortener.py`, строки 40–55  
   - **Описание:** При наличии кэшированного URL (`cached_url`) функция `get_url_and_increment` всё равно выполняет запрос к PostgreSQL для проверки `is_deleted` и `expires_at`. Это полностью нивелирует смысл кэширования, нарушая нефункциональное требование производительности (P99 < 50ms, hit ratio >90%).  
   - **Предложение:** Убрать запрос к БД при cache hit. Доверять кэшу, но при удалении/истечении ссылки инвалидировать кэш (что уже делается). Для дополнительной безопасности можно хранить в Redis также срок действия и флаг активности.

### 🟡 Важные проблемы (необходимо исправить до запуска)

2. **Некорректная инициализация `Base` для Alembic**  
   - **Файл:** `src/models/__init__.py`, строка 6  
   - **Описание:** `Base = UrlMapping.metadata` — это metadata, а не класс `DeclarativeBase`. Alembic не увидит таблицы, миграции не сработают.  
   - **Предложение:** Заменить на `from src.models.url_mapping import Base` или явно экспортировать `Base` из `url_mapping.py`.

3. **Отсутствует импорт `status` в `stats.py`**  
   - **Файл:** `src/services/stats.py`, строка 5  
   - **Описание:** Используется `status_code=404`, но `from fastapi import status` не импортирован. При вызове `get_stats` возникнет `NameError`.  
   - **Предложение:** Добавить `from fastapi import status` или использовать `HTTPException(status_code=404, ...)` с числовым значением.

4. **Ошибка в вычислении `retry_after` в rate limiter**  
   - **Файл:** `src/middleware/rate_limiter.py`, строка 57  
   - **Описание:** Выражение `float(await redis.zrange(key, 0, 0, withscores=True)[0][1])` может привести к ошибке при пустом списке и сложночитаемо.  
   - **Предложение:** Упростить: `retry_after = window` (всегда возвращать 60 секунд) или корректно вычислить оставшееся время через `ttl` ключа.

5. **Отсутствие обработки ошибок Redis в rate limiter**  
   - **Файл:** `src/middleware/rate_limiter.py`, строки 35–60  
   - **Описание:** При недоступности Redis middleware упадёт с 500, хотя архитектура требует fallback к PostgreSQL.  
   - **Предложение:** Обернуть операции с Redis в try/except, логировать ошибку и пропускать запрос (не ограничивать).

6. **Некорректное закрытие Redis при shutdown**  
   - **Файл:** `src/main.py`, строка 39  
   - **Описание:** `await redis.close()` закрывает только одно соединение, а не пул.  
   - **Предложение:** Вызвать `close_redis_pool()` из `src/db/redis.py`.

7. **Отсутствие fallback при недоступности Redis**  
   - **Файл:** `src/db/redis.py`  
   - **Описание:** Нет обработки ошибок при создании пула. Если Redis не запущен, приложение не стартует.  
   - **Предложение:** Добавить try/except, логировать предупреждение и позволить приложению работать без Redis (с запросами напрямую к БД).

8. **Отсутствует импорт `Optional` в `stats.py`**  
   - **Файл:** `src/schemas/stats.py`, строка 6  
   - **Описание:** Используется `Optional[datetime]`, но `from typing import Optional` не добавлен.  
   - **Предложение:** Добавить импорт или заменить на `datetime | None` (Python 3.11+).

### 🟢 Минорные замечания (рекомендуется исправить)

9. **Неиспользуемый импорт `update`**  
   - **Файл:** `src/services/url_shortener.py`, строка 8  
   - **Описание:** `from sqlalchemy import select, update` — `update` не используется.  
   - **Предложение:** Удалить.

10. **Неиспользуемый параметр `request`**  
    - **Файл:** `src/api/redirect.py`, строка 15  
    - **Описание:** Параметр `request: Request` не используется в теле функции.  
    - **Предложение:** Удалить или зарезервировать для будущего использования.

11. **Потенциальная проблема с `server_default` для Boolean**  
    - **Файл:** `src/models/url_mapping.py`, строка 16  
    - **Описание:** `server_default="false"` (строка) может быть некорректно интерпретировано PostgreSQL.  
    - **Предложение:** Использовать `server_default=sa.text('false')` как в миграции.

12. **Ложные срабатывания в SSRF-проверке**  
    - **Файл:** `src/utils/url_validator.py`, строка 28  
    - **Описание:** `if block in hostname` может сработать на подстроке (например, `10.` в `10example.com`).  
    - **Предложение:** Использовать `ipaddress` для проверки, либо точное совпадение для IP, для доменов — сравнивать с `hostname == block`.

13. **Глобальная модификация settings в тесте**  
    - **Файл:** `tests/test_rate_limiter.py`, строка 10  
    - **Описание:** Изменение `settings.RATE_LIMIT_PER_MINUTE` влияет на другие тесты.  
    - **Предложение:** Использовать `monkeypatch` или временную фикстуру.

14. **Слишком широкое исключение в тесте**  
    - **Файл:** `tests/test_url_validator.py`, строка 9  
    - **Описание:** `pytest.raises(Exception)` перехватывает любые исключения, включая ошибки тестов.  
    - **Предложение:** Уточнить до `pytest.raises(HTTPException)`.

15. **Дублирующаяся установка зависимостей в Dockerfile**  
    - **Файл:** `Dockerfile`, строки 5–6  
    - **Описание:** Две команды `pip install`: сначала `-e ".[dev]"`, потом `.`. Вторая перезаписывает первую.  
    - **Предложение:** Объединить: `RUN pip install --no-cache-dir .` (без dev).
