# TODO REST API

Минималистичный REST API для управления списком задач (TODO).

## Возможности

- Создание задачи
- Получение списка всех задач (от новых к старым)
- Отметка задачи как выполненной/невыполненной
- Удаление задачи
- Health check эндпоинт

## Технологии

- Python 3.11+
- FastAPI
- SQLAlchemy 2.0 (async)
- SQLite (WAL mode)
- Pydantic v2
- Alembic (миграции)
