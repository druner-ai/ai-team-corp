# AI Team Corp — TDD Edition

Автоматическая генерация кода AI-командой с PR в GitHub.

## Архитектура (TDD)

| Роль | Модель | Функция |
|:---|:---|:---|
| **Архитектор** | GLM-5.2 | Проектирует решение, пишет архитектурный документ |
| **Test Designer** | DeepSeek V4 Pro | Пишет тесты **по архитектуре, не видя кода** |
| **Разработчик** | DeepSeek V4 Pro | Пишет код, который **проходит тесты** |
| **QA Gate** | Codestral 2508 | Запускает тесты, проверяет качество |
| **DevOps** | DeepSeek V4 Pro | Dockerfile, docker-compose, CI/CD |

## Ключевое отличие: TDD

**Традиционный подход:** код → тесты → фикс (тесты подгоняются под код)

**TDD-подход:** архитектура → тесты → код под тесты (тесты определяют контракт)

Вдохновлено [AgentCoder](https://arxiv.org/abs/2312.13010) и [Nx Self-Healing CI](https://nx.dev/).

## Запуск

```bash
uv run python main.py "Создай URL shortener: FastAPI + SQLite, без ORM"
```

## Результат

- PR в GitHub с кодом
- CI/CD (GitHub Actions) — автоматический запуск тестов
- Отчёт о выполнении в `output/<timestamp>/`
